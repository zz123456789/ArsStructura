# Ars Structura · 构筑魔艺

Minecraft **1.20.1** / Forge **47.4.10** / Ars Nouveau **4.12.7** 附属模组。采用 Mojang official 1.20.1 mappings、Java 17、根包 `com.arsstructura`、模组 ID `arsstructura`。客户端与服务器必须安装相同版本。没有修改或打包 Ars Nouveau 源码。

原创代码、资源和文档采用 **LGPL-3.0-only**，授权范围与第三方材料说明见 [LICENSING.md](LICENSING.md)。[源码](https://github.com/zz123456789/ArsStructura) · [问题反馈](https://github.com/zz123456789/ArsStructura/issues)。

## 使用

1. 在「构筑魔艺」创造标签中取出建造之板或预制建造之板，也可使用合成配方获得。
2. 手持建造板，**潜行＋左键方块**绑定点 1（青色边框），**潜行＋右键方块**绑定点 2（橙色边框）。两点之间显示淡金色选区线框，重合时显示两层不同颜色的边框。两点取包含端点的最小/最大坐标，第二个角确定后分 tick 采集结构。采集期间保持手持、保持选区区块加载。
3. **普通右键方块**：点击面的相邻位置成为建筑最小角锚点，显示半透明方块。预览不会放置真实方块。默认仅渲染视距 96 格以内的非空气方块。
4. **持板普通右键空闲的 Ars Nouveau 仪式火盆**装入仪式，保留已设置的锚点。此时火盆点燃并等待；**切换到空主手，再右键火盆**，通过 Ars 原生交互启动。默认蓄能 **100 tick（正常游戏速度下 5 秒）**，随后分批建造。只有装入者可以启动，红石信号会暂停仪式。
   火盆附近 6 格内需有足够 Source；装入时支付 100 Source 和配置的燃料，建造时每个成功尝试放置的方块消耗 10 Source，不足时暂停。默认保留建造板，不消耗额外燃料。装入后取消不会退还已付成本，启动与重载不会重复扣除装入成本。
5. **预制板右键空气**打开文件界面；普通建造板右键空气取消预览。切换所持物品、维度或退出世界会清理客户端预览。

普通建造板合成：` SG / SPS / GS `，S=平滑石、G=魔源宝石、P=纸。
预制板合成：` GR / GTG / RG `，G=金锭、R=红石、T=建造之板。升级合成生成一块新的空白预制板，先升级再选择建筑。

两个物品直接引用 Ars Nouveau 原生仪式之板模型：建造板使用 `ritual_restoration`，预制板使用 `ritual_binding`。石板轮廓、像素风格和手持显示与原生仪式之板一致，分别使用青色与紫色符文；这两张外观与对应原生仪式之板共用，名称和提示用于区分功能，资源包覆盖也会随之生效。

## 本地预制与 Litematica

文件目录为当前游戏实例的 `config/ars_construction_tablet/prefabs/`，由客户端创建、读写。服务器不接触客户端文件系统。

- 「保存 NBT」：服务端发送当前建筑，客户端保存本模组 `.nbt` 格式。
- 「导出」：按名称框右侧的 `.nbt` / `.litematic` 选择保存格式。
- 将外部 `.litematic` 文件放进上述目录，点击刷新、选中文件、导入。导入经过服务端再次验证才会写入手持预制板。
- 预览按钮显示**当前物品里的建筑**；要预览本地文件，应先导入并设置锚点。
- 重命名同时更新文件内名称；删除需在 5 秒内再次点击确认。不会覆盖已有同名文件。

支持 **Minecraft 1.20.1 / DataVersion 3465 的 Litematica 格式 5、6**，导出格式 6 / SubVersion 1。实现多区域间距、负方向选区、跨 long 位流、方块状态及允许的方块实体。不同区域中冲突的非空气方块会拒绝导入。未知方块/属性会报错，不会悄悄变成空气。

不需要安装 Litematica；这是文件格式兼容，不是 Fabric 模组运行兼容。旧版、新版 Minecraft 的文件需要先用相应工具转换为 1.20.1 文件。实体、计划刻、实体动画等不在复制范围内。来源和位流规则见 [格式说明](docs/LITEMATIC_FORMAT.md)。

## 配置与安全边界

服务端配置在世界的 `serverconfig/arsstructura-server.toml`；客户端渲染配置在 `config/arsstructura-client.toml`。服务端配置会同步给客户端。

| 配置 | 默认值 |
| --- | --- |
| 最大边长 / 包围盒体积 | 640 / 262,144,000 |
| 保存方块数上限 | 65,536 |
| 单个压缩结构/文件上限 | 1 MiB，硬上限 1 MiB |
| NBT 解压/分配预算 | 32 MiB |
| NBT 嵌套深度 | 32 |
| 世界内创造物品结构备份 | 64 MiB / 8192 个不同结构，按内容去重 |
| 每 tick 扫描 / 建造预算 | 4096 / 64 |
| 启动后蓄能时间 `ritualWarmupTicks` | 100 tick（5 秒），可设为 0 |
| 保存空气 / 方块实体 | 否 / 是 |
| 复制容器内容、战利品表等 | 否 |
| 强制替换 | 否 |
| 装入 Source / 每方块 Source | 100 / 10 |
| 燃料物品 / 数量 | 紫水晶碎片 / 0 |
| 消耗板本体 / 耐久损耗 | 否 / 0 |
| 火盆与目标锚点距离上限 | 256 |
| 预览距离 / 透明度 | 96 / 0.35 |
| 预览可见方块上限 | 65,536 |

所有限制共同生效。640³ 是坐标范围上限，不意味着允许一个物品保存 2.62 亿个非空气方块。Litematica 的稠密数组还有独立处理预算：`min(maxVolume, maxNbtBytes / 8)`，默认 4,194,304 个位置；超过时明确拒绝，避免高度压缩的大片空气导致长时间卡顿。

默认禁止命令方块、结构方块、基岩、传送门、刷怪笼、TNT、仪式火盆等。允许复制的方块实体由白名单配置；默认包括常用原版容器、告示牌、旗帜、床等。容器物品和战利品数据默认清除，告示牌执行命令的点击事件会拒绝。服务器可显式启用容器内容复制并添加可信模组的方块实体类型。

默认只替换空气、草、水等可替换方块；即使启用强制替换，也不覆盖已有方块实体、不可破坏方块和黑名单方块。发送 Forge 放置/破坏保护事件，兼容遵循这些事件的领地保护；其他保护插件需单独验收。

建造使用 Source 创造结构方块，不收集玩家背包中的建筑材料。`allowSurvivalImport=false` 可将外部预制导入限制为创造玩家/管理员。客户端不能通过本模组网络包直接写物品 NBT。导入有字节、深度、注册表、坐标、块数量、权限、手持物品 UUID/版本与上传频率校验。

建筑在分 tick 采集期间不是世界的瞬时快照；期间修改源区域会反映在尚未采集的位置。建造目标未加载、拥有者离线或跨维度时暂停。装入后的待启动状态、剩余蓄能时间和建造进度保存在世界数据中，重启可继续。拆除火盆或替换其仪式会取消任务，保留已放置部分，不回滚或退还已经花费的 Source。

创造模式物品栏回写只包含建筑摘要时，服务器使用当前世界的可信结构备份恢复完整内容，保留物品版本与元数据。备份存于世界 `data/arsstructura_tablet_structures.dat`，受 `maxBackupBytes` 与 `maxBackupStructures` 约束；达到上限会拒绝新的结构保存/导入并保留旧物品。正常物品仍自带完整压缩结构。跨世界或跨服务器分享建筑请使用本地预制导出/导入；客户端保存的创造工具栏摘要不能替代预制文件。

## 开发与构建

`libs/` 中是从用户指定整合包复制的原始依赖：Ars Nouveau 4.12.7、Curios 5.14.1、GeckoLib 4.8.4、Patchouli 85。仅用于开发依赖，不会嵌入产物；向其他开发环境分享源码时，需要自行提供这些依赖 JAR。

```powershell
.\gradlew.bat compileJava
.\gradlew.bat test
.\gradlew.bat runGameTestServer
.\gradlew.bat build
```

产物：`build/libs/arsstructura-0.1.0.jar`。将其放入客户端与服务器的 mods 文件夹，替换旧版附属模组。0.1.0 为首次公开发布编号，承接已测试的开发版 1.0.2，不是功能回退。项目保留 Forge 47.4.10 编译基线；用户整合包 Forge 47.4.22 的实际画面与其他模组组合须按下面清单验收。

Ars API 核对记录见 [ARS_API.md](docs/ARS_API.md)。测试项目及需要游戏内验证的项目见 [ACCEPTANCE.md](docs/ACCEPTANCE.md)。
