## 操作与结构

- [ ] 普通/预制板在生存与创造模式下，潜行左键绑定点 1，不挖掉方块；潜行右键绑定点 2，不打开容器或使用其他方块交互。
- [ ] 交换两角、负世界坐标、相同角均取正确的包含端点区域；有聊天提示和采集进度。
- [ ] 点 1 显示青色单方块边框、点 2 显示橙色边框，选区显示淡金色 AABB；只有点 1 时也显示，重合时仍能分辨两色。遮挡后有淡线，切换物品、维度、退出世界和按 F1 时隐藏。
- [ ] 两种板子的背包图标和手持轮廓与 Ars 原生仪式之板一致；普通板青色、预制板紫色。检查原版资源包和当前整合包资源包。
- [ ] 跨维度绑定被拒绝；未加载选区、大于边长/体积/方块数限制时提示，不丢失原有已保存结构。
- [ ] 选区含楼梯、轴向原木、水、告示牌、带名称箱子，保存后信息中尺寸与非空气方块数正确。
- [ ] 普通右键六个面的锚点都位于被点击面的相邻方块位置；保留相同相对布局。
- [ ] 普通板右键空气取消预览，预制板右键空气打开界面；潜行右键方块始终绑定点 2。

## 仪式火盆

- [ ] 使用两个板中的任意一种普通右键空闲火盆，只装入仪式；火盆点燃但不开始建造。切换空主手再右键后进入蓄能，默认等待 5 秒才放置第一批方块；火焰、施法音效及结束熄火由 Ars 原生火盆处理。
- [ ] 将板子移到副手、主手留空后仍可启动，不能因同一次点击的副手交互重复装入或出现“火盆已有仪式”误提示。
- [ ] 缺少结构、锚点、装入 Source、可选燃料、维度不符、超距离或世界边界时拒绝装入并提示。非装入者不能启动；红石信号阻止启动，并暂停/恢复已启动的蓄能和施工。
- [ ] 默认不消耗板本体；装入时收取一次 Source/可选燃料，每方块 Source 正确扣除，耗尽后暂停、补充后继续；重载和重复空手点击不会重复收装入费用。
- [ ] 待启动时退出重进仍等待空手启动；蓄能途中重进继续剩余时间，不跳过或重置。修改 `ritualWarmupTicks` 后新装入仪式使用新时长，0 表示关闭蓄能等待。
- [ ] 空气、草、水允许替换；实心已有建筑默认跳过；开启强制替换后仍保护黑名单、已有方块实体及保护插件区域。
- [ ] 方块朝向、楼梯上下半、原木轴等 BlockState 恢复正确；告示牌文字、旗帜图案、箱子名称正确。
- [ ] 默认不复制箱子内物品/战利品；显式启用 keepInventories 后按服务器策略验证。
- [ ] 无 Source、保护事件取消时不免费建造或改变原有方块实体；跳过数/恢复失败数有完成提示。
- [ ] 建造中退出、重启、卸载目标区块后能安全暂停和恢复；等待、蓄能、施工中拆火盆均安全停止，物品不会复制掉落。替换仪式后停止旧任务。
