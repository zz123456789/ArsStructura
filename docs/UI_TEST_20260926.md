## 修复

1.0.1 切换快捷栏时，被动预览下载可能早于原版选槽同步到达服务端，触发“请手持请求对应建造板”的误提示。`ClientTabletController` 现在观察选槽及双手物品 UUID，等待手持状态稳定后再发起被动请求。保留全部服务端物品身份校验。版本更新为 1.0.2。

修复后 `gradlew.bat build runGameTestServer --console=plain` 成功，31 项 JUnit 和 6 项真实 Forge / Ars GameTests 全部通过。自动测试覆盖压缩/NBT 限制、注册表和属性校验、Litematica 编解码、任务持久化、Source 扣费、碰撞与保护、空手激活、红石及创造模式备份等；详细范围见 [验收清单](ACCEPTANCE.md)。
